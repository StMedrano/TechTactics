# Shared Notebook

Use this file for durable lessons discovered while operating the Web Growth Agent.

## Initial principles
- Businesses with no website are easy to identify but are not automatically good customers; qualification still matters.
- Existing websites should be criticized only with recorded, reproducible evidence.
- A personalized demo can be more persuasive than generic "we build websites" outreach.
- Generated outreach should mention only public business facts and audit evidence.
- Track wins/losses by category and market so future scouting becomes a closed feedback loop.

- Preserve the rationale behind important changes, not only the final decision.
- When a recurring task works, convert it into a reusable skill, template, checklist, component, or integration.
- Documentation should be produced while the work is done so future agents can understand how and why the system was built.
- Current task context is temporary; durable company truth belongs in owned files.
