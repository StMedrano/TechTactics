# Skills

Skills are written instructions that a TechTactics worker follows.

## Rule

If a process is repeated, important, or easy to perform inconsistently, turn it into a written skill rather than relying on chat history.

Each skill should state:
- Goal
- Inputs
- Ordered procedure
- Evidence required
- Output/artifact
- Approval gates
- Failure handling
- Documentation/memory updates required after completion

## Current department skills

The worker-specific operating contracts live under `../agents/`.

Scout → Audit → Qualify → Create Demo → Prepare Outreach → Human Approval → Contact → Proposal → Build → Care Plan → Learn
