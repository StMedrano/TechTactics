# Skills

Skills are written instructions that a TechTactics worker follows.

## Rule

If a process is repeated, important, or easy to perform inconsistently, turn it into a written skill rather than relying on chat history.

Each skill should state:
- Goal
- Inputs
- Ordered procedure
- Evidence required
- Output/artifact
- Approval gates
- Failure handling
- Documentation/memory updates required after completion

## Current department skills

The worker-specific operating contracts live under `../agents/`.

The current website-growth flow is:

Scout → Audit → Qualify → Create Demo → Prepare Outreach → Human Approval → Explicit Zoho Send → Proposal → Build → Care Plan → Learn

Back-office flows:
- Accounting/Tax: Gather period/context → Read Zoho Books → Reconcile facts/questions → Prepare close/tax packet → Human/CPA review.
- Legal: Gather document/jurisdiction/context → Extract obligations/deadlines → Issue-spot/draft → Human/attorney review → Record decision.

As TechTactics starts delivering more client websites, proven delivery work should become reusable skills for onboarding, content collection, design, development, integrations, QA, launch, analytics, and care plans.

## Designer Skills

### techtactics-ui-design

Mandatory for every Designer-generated website concept.

This skill provides:

- Persuade / Operate / Read / Experience surface routing
- brand and context recovery
- information architecture
- semantic design-system rules
- responsive behavior
- WCAG 2.2 AA accessibility guidance
- local-business conversion principles
- purposeful interaction and motion rules
- anti-generic visual direction
- factual-integrity requirements
- final visual-quality verification

The Designer must load this skill before producing a website design.
