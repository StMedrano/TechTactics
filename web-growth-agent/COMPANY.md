# TechTactics Web Growth Department

**Parent business:** TechTactics  
**Purpose:** Find local businesses that would benefit from a new or improved website and turn verified opportunities into high-quality, human-reviewed sales proposals.

## Brand promise
SMART SOLUTIONS. SECURE CONNECTIONS.

## Department loop
Scout → Audit → Qualify → Create Demo → Prepare Outreach → Human Approval → Contact → Proposal → Build → Care Plan → Learn

## Non-negotiables
- Evidence before claims.
- Human approval before outreach.
- No fake reviews, fake performance measurements, or invented business facts.
- Respect API/provider terms and applicable communications laws.
- Favor long-term reputation over volume.

## AI-native operating model

Build the department with the AI team present rather than trying to onboard the team after the process is already mature. Every worker needs explicit **skills, memory, context, tools, and a lane**.

- Skills live as written operating instructions.
- Memory lives in company-owned files, not in a model's private recollection.
- Context is assembled for the current lead/project/run.
- Tools are permissioned explicitly and remain behind approval gates where risk exists.
- Multiple specialized agents own distinct lanes and hand work to one another through durable artifacts.

The department should record both **what** changed and **why**. Documentation is part of completing the work, not a separate cleanup step later.
